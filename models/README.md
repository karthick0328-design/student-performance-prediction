# Trained Models Directory

This directory stores the serialized machine learning pipelines generated by `src/train_model.py`.

- `student_model.joblib`: The complete scikit-learn Pipeline object encapsulating:
  1. Feature preprocessing via `ColumnTransformer` (StandardScaler for numeric features, OneHotEncoder for categorical features).
  2. The selected high-performing algorithm (`RandomForestRegressor` with hyperparameter regularization: `n_estimators=100`, `max_depth=5`, `min_samples_split=5`, `random_state=42`).
- Saved with `joblib.dump()` and safely reloaded by `src/predict.py` and `app.py`.
