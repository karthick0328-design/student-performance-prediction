About This Project
Learn more about the problem, methodology and technical details.
Problem Statement
Predict student academic performance using demographic, familial, study habit and behavioral data to support early intervention.
Objectives
  • Analyze student data and identify key factors
  • Build a machine learning model for prediction
  • Provide insights through visualization and evaluation
Dataset Source
UCI Student Performance Dataset (student-mat.csv)
Source: https://archive.ics.uci.edu/dataset/320/student+performance
License: Open data (academic use)
Technologies Used
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Flask
Ethical Considerations
This model is for educational analysis only. Predictions should not be used for high-stakes decisions about individual students.
